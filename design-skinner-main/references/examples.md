# Examples

## Simple Color Change

`Use $design-skinner to change the Header module primary color to #FDC708 and keep everything else unchanged.`

## Radius Change

`Use $design-skinner to change the Card module color to #1E66FF and radius to 12.`

## Shadow Change

`Use $design-skinner to change the Button module to green and reduce the shadow.`

## SVG Workflow

1. inspect the SVG tokens
2. map the module
3. recolor only the requested tokens
4. verify the final SVG still matches the original geometry

## JimiRing Theme Direction

- original theme: yellow
- custom theme: Any color

Example:

`Use $design-skinner to convert the original yellow JimiRing screens to the custom blue skin by updating shared brand and button tokens first.`
