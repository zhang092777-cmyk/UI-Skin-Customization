# Token Mapping

## Color

Update:

- Figma shared styles
- `fill`
- `stroke`
- `stop-color`
- text fill
- icon fill
- overlay fills
- state colors

## Radius

Update only when requested:

- `rx`
- `ry`
- corner-related border radius tokens

## Shadow

Update only when requested:

- SVG filter blur strength
- CSS `box-shadow`
- CSS `filter: drop-shadow(...)`

## Keep Fixed

- position
- size
- spacing
- copy
- asset placement

## Figma Mapping

- `brand` -> primary accent
- `button` -> primary action
- `button_regular` -> neutral action
- `bg` -> page background
- `card` / `card_fill` / `card_stroke` -> surface system
- `text_primary` -> main text
- `text_secondary` -> supporting text
